# Jupyter notebooks for different tasks
## *Zoologico de modelos de vision*

| File / Archivo | EN | ES |
|---|---------|---------|
| `classCounterTXTFiles.ipynb` | It is used to count the total number of instances for each class in a folder with `.txt` files. | Sirve para contar el total de instancias de cada clase en los archivos `.txt` de una carpeta. |
| `comparisonLowLightImageEnhancementTechniques.ipynb` | Compares different low-light image enhancement techniques to improve detection in YOLO models and calculates the computational cost. | Compara diferentes técnicas de realce de imágenes de baja iluminación para mejorar la detección en modelos YOLO y calcula el costo computacional. |
| `comparisonMetricsGraphs.ipynb` | Compares metrics in graphs by reading `.csv` files. | Compara las métricas en gráficos leyendo archivos `.csv`. |
| `findDarkestImageFolder.ipynb` | Gets the darkest images in a folder. | Obtiene las imágenes más oscuras dentro de una carpeta. |
| `imageDataAugmentationTechniques.ipynb` | Shows the different image data augmentation techniques. | Muestra las diferentes técnicas de aumento de datos de imágenes. |
| `labelCensoringReinforcedYOLO.ipynb` | Censoring based on the coordinates obtained from the bounding boxes in `.txt` files and reinforced with detections from a YOLO model. | Censura basada en las coordenadas obtenidas de las cajas delimitadoras en los archivos `.txt` y reforzada con las detecciones del modelo YOLO. |
| `yoloModelTrainingEvaluation.ipynb` | Create a `.yaml` file, train and evaluate a YOLO model. | Crea un archivo `.yaml`, entrena y evalúa un modelo YOLO. |
